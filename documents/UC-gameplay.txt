Use Case: Game Play
* Actor: Student
* Goal: The basics of the game play
* Preconditions: Actor has accessed the web page
* Trigger: Accesses website/flashcard
* Main flow: Numbered steps, actor action ? system response, alternating

1 Student Presses New GameScreen Refreshes.  If timer options in enabled then the users must click starts and then the system Displays 2 numbers with the default operation of last operation used. If the timer option is not enabled the system starts with the display of the problem
2 Student Enters or Updates Answer – press return or check buttonReviews the answer and if correct turns the border to green if wrong then red.  If correct add to number correct for this session, if wrong add to the number wrong for this session. Display the running count of total problems, number of correct and wrong answers. If the timer expires before the answer is entered then the border turns red and the user can’t enter the answer.3 Presses new problemScreen Refreshes.  Displays 2 numbers with the default operation of last operation used. If timer option then timer resets to default

* Postconditions: Actor leaves the page.
* Alternate/edge flows: What happens on wrong answers, invalid input, edge cases (division by zero, negative results, etc.)
1 User Clicks new operandScreen Refreshes.  Displays 2 numbers with the new operand.  Current game counts don’t change. Operands include +,-,*,/,Random2 Enters or Updates Answer – press return or check buttonReviews the answer and if correct turns the border to green if wrong then red.  If correct add to number correct for this session, if wrong add to the number wrong for this session. Display the running count total problems number of correct and wrong answers.3 Presses new problemScreen Refreshes.  Displays 2 numbers with the default operation of last operation used.
