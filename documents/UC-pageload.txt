Use Case: pageload
•	Actor: Student
•	Goal: Display the initial screen when the page is loaded
•	Preconditions: None
•	Trigger: Page is opened from the primary menu
•	Main flow:
1. Click on link to game
    System displays the page. 
    1.1. the page has an options menu (see UC-Options.txt)
    1.2. A HTML Section flashcard that contains:
        1.2.1. a Form area for the problem. Use the style flashcard.  initially form doesn't have any values.
        1.2.2. Text field for the answer to be entered with a submit button tied to the text field.  The answer can be submitted by pressing return in the text form or clicking the submit button
        1.2.3. An area that dispalys a list of operands.  The current operand is the primary color (--primary) and the other values are secondary (--secondary).  
        The values are +,-,*,/,Random.  The value selected initially is based on the cookie for operand.  If this is the first load or if the cookies have been cleared then the default is "+".
        1.2.4. Go/Next Button.  Initially the value is Go. 
        1.2.5. Pause Timer Button that allows the user to pause the timer. It can have 2 values start and pause.  The the timer option is not enabled then the button doesn't show.
    1.3. New Game button - On click it clears out any score keeping, timers
    1.4. Timer displays - Two Text display to show the timers. One timer is for the game, while the other is for the specific problem.  It is only displayed if the timer option is enabled
    1.5. Stats Section.  This is only shown if Stats are turned on in the options menu.
        1.5.1 Text field that display number correct
        1.5.2 Text field that displays number wrong for this game.  
        1.5.3 Text field that shows total number of problems for this session

•	Postconditions: 
1. Focus is on the Go Button
